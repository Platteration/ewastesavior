# update both.

# Syntax:
#   [all] / [x86_64] / [i686]    section: which payloads the lines apply to
#   CONFIG_X=y                   must be built in
#   CONFIG_X=m                   must be a module
#   CONFIG_X=y|m                 built in or module
#   CONFIG_X="text" / =123       exact value
#   # CONFIG_X is not set        must be off (absent, "is not set" or =n)
# Other lines starting with '#' are comments.
