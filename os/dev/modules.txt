# os/dev/modules.txt - kernel modules of the SaviorOS dev image.
#
# The dev image uses the Ubuntu 24.04 generic kernel (os/dev/build.sh). These
# modules, plus everything they depend on (modules.dep) and their soft
# dependencies (modules.softdep, e.g. r8169 -> realtek), go into
# /lib/modloop.sqfs. Syntax, one module per line:
#   name              required: the build fails if the kernel has neither a
#                     module nor a built-in driver of that name
#   optional: name    skipped (with a note) when the kernel lacks it
#   a|b               the first of these names that exists (renamed drivers)
#   firmware: name package
#                     when module "name" is in the modloop, every firmware
#                     file it asks for (modinfo -F firmware) is taken from
#                     the Ubuntu package (apt-get download) into firmware/
# "-" and "_" are interchangeable. Modules the kernel has built in are fine
# (they need no file). The production list is the Kconfig in
# os/buildroot/board/savior/linux (DESIGN 14).
